Text widget for displaying text. Support setting text size, color, alignment, font.

## Create UI widget

```js
import { createWidget, widget } from '@zos/ui'

const text = createWidget(widget.TEXT, Param)
```

## Cursor and text editing

> Start from API_LEVEL `4.0`.

Call these methods on the text widget instance returned by `createWidget(widget.TEXT, Param)`. Call `enableCursor(true)` to enable the cursor before using these methods.

### enableCursor

```ts
enableCursor(enable: boolean): void
```

Enables or disables the text cursor. Set `enable` to `true` to enable it or `false` to disable it.

### getCursorPos

```ts
getCursorPos(index: number): { x: number; y: number }
```

Gets the cursor position for the character at `index`. Returns a coordinate object:

| Property | Type | Description |
| --- | --- | --- |
| x | `number` | Horizontal offset relative to the text widget |
| y | `number` | Vertical offset relative to the text widget |

### getCursorIndex

```ts
getCursorIndex(x: number, y: number): number
```

Gets the cursor character index from coordinates. Both `x` and `y` are offsets relative to the text widget, using the same coordinate system as the result of `getCursorPos`.

### getTextCount

```ts
getTextCount(): number
```

Gets the number of characters in the text.

### insertString

```ts
insertString(index: number, str: string): void
```

Inserts the string `str` at the character index `index`.

### deleteCharacter

```ts
deleteCharacter(index: number): void
```

Deletes one character at the character index `index`.

### getCursorHeight

```ts
getCursorHeight(): number
```

Gets the cursor height in pixels.

### getLineHeight

```ts
getLineHeight(): number
```

Gets the text line height in pixels.

### Cursor and text editing example

This example enables the cursor, inserts and deletes text, then queries the character count, cursor position, and heights.

```js
import { align, createWidget, text_style, widget } from '@zos/ui'

Page({
  build() {
    const text = createWidget(widget.TEXT, {
      x: 40,
      y: 120,
      w: 320,
      h: 160,
      color: 0xffffff,
      text_size: 28,
      align_h: align.LEFT,
      align_v: align.TOP,
      text_style: text_style.WRAP,
      text: 'Hello',
    })

    text.enableCursor(true)
    text.insertString(5, ', Zepp OS')
    text.deleteCharacter(5)

    // The text is now "Hello Zepp OS".
    console.log(text.getTextCount())

    const position = text.getCursorPos(0)
    console.log(position.x, position.y)
    console.log(text.getCursorIndex(position.x, position.y))
    console.log(text.getCursorHeight(), text.getLineHeight())
  },
})
```

## Code example

```js
import { createWidget, widget, align, prop, text_style, event } from '@zos/ui'

Page({
  build() {
    const text = createWidget(widget.TEXT, {
      x: 96,
      y: 120,
      w: 288,
      h: 46,
      color: 0xffffff,
      text_size: 36,
      align_h: align.CENTER_H,
      align_v: align.CENTER_V,
      text_style: text_style.NONE,
      text: 'HELLO, Zepp OS'
    })

    text.addEventListener(event.CLICK_DOWN, (info) => {
      text.setProperty(prop.MORE, {
        y: 200
      })
    })

    const textWithFont = createWidget(widget.TEXT, {
      x: 96,
      y: 300,
      w: 288,
      h: 46,
      color: 0xffffff,
      text_size: 36,
      align_h: align.CENTER_H,
      align_v: align.CENTER_V,
      text_style: text_style.NONE,
      font: 'fonts/custom.ttf',
      text_i18n: {
        'en-US': 'Hello Zepp OS',
        'zh-CN': '你好 Zepp OS'
      }
    })
  }
})
```

### Example 2

```js
import { align, createWidget, widget } from '@zos/ui'

const rootContainer = createWidget(widget.VIRTUAL_CONTAINER, {
  layout: { x: '10vw', y: '10vh', width: '80vw', height: '50vh' },
})

const groupRoot = createWidget(widget.GROUP, {
  parent: rootContainer,
  layout: {
    display: 'flex',
    'flex-flow': 'row wrap',
    'column-gap': '20',
    'row-gap': '10',
    'justify-content': 'space-evenly',
    'align-items': 'center',
    width: '100%',
    height: '100%',
  },
})

for (let i = 0; i < 3; i += 1) {
  groupRoot.createWidget(widget.TEXT, {
    text: 'hello zepp os',
    color: 0x34e073,
    align_v: align.CENTER_V,
    layout: {
      width: '30%',
      height: '25%',
      'font-size': '16',
    },
  })
}
```
