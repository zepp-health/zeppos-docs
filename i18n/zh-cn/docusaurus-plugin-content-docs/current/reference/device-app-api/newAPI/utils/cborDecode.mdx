# cborDecode

> API_LEVEL `5.0` 开始支持，API 兼容性请参考 [API_LEVEL](../../../../guides/framework/device/compatibility.md)。

将 CBOR 格式的 `ArrayBuffer` 解码为 JS 值。

## 类型

```ts
function cborDecode(buffer: InputBuffer): Result
```

## 参数

### InputBuffer

| 类型                     | 说明                          |
| ------------------------ | ----------------------------- |
| <code>ArrayBuffer</code> | 需要解码的 CBOR `ArrayBuffer` |

### Result

| 类型                 | 说明           |
| -------------------- | -------------- |
| <code>unknown</code> | 解码后的 JS 值 |

## 代码示例

```js
import { cborEncode, cborDecode } from '@zos/utils'

const buffer = cborEncode({ enabled: true, count: 3 })
const value = cborDecode(buffer)
console.log(value)
```
